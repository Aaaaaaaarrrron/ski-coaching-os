# YUSIMI Beta v2.3.0 — Visual Transformation

기능/데이터 연결은 v2.2.0과 동일하게 유지하면서, 화면 구조와 디자인 시스템을 전면 재설계했습니다.
방향: "Alpine Studio" — 프리미엄 스키 아카데미 + 영상 분석 도구 + 성장 기록 서비스가 결합된 언어.

## 채택한 방향
분석 후 제안한 3가지(안전형 / 프리미엄형 / 차별화형) 중 **프리미엄형**을 선택해 구현했습니다.
- 안전형: 토큰만 갈아끼우고 레이아웃 유지 → 체감 변화 부족으로 기각
- 차별화형: 완전 다른 인터랙션 패턴(제스처 기반 스와이프 UI 등) → 구현 리스크·회귀 위험 커서 기각
- **프리미엄형(채택)**: 역할별 전용 레이아웃 재설계 + 에디토리얼 타이포(Fraunces) + 다크 네이비 앱셸 + 라이트 콘텐츠 캔버스 조합

## 시각적으로 크게 달라진 10가지
1. 디스플레이 서체(Fraunces) 도입 — 일반 SaaS 산세리프 일색에서 탈피
2. 상단바를 라이트 → 다크 네이비 글래스로 전환, 사이드바와 통일된 "앱셸" 느낌
3. Coach 홈: 통계 카드 나열 → 다크 커맨드 헤더 + 오늘 세션 타임라인 스트립
4. Coach Batch: 좌우 대칭 그리드 → 영상이 주인공인 워크스페이스(영상 고정 좌측, 피드백 우측, 미디어는 하단 필름스트립)
5. Admin 홈: 통계 그리드 나열 → "지금 처리할 업무" 우선순위 큐가 최상단
6. Parent 홈: 그라데이션 커버만 있던 화면 → 실제 최근 강습 사진이 화면 중심에 오는 매거진 히어로
7. 리포트 카드가 어두운 헤더 + 색상 구분된 피드백 블록의 "리포트" 톤으로 통일
8. 그레인 텍스처(다크 헤더에 미세한 노이즈) 적용으로 평면적인 느낌 제거
9. 버튼/그림자/글로우 계층 재정의 — 주요 CTA(Evening Batch 시작)에 teal glow 강조
10. 모바일 하단 내비게이션 + 고정 저장 액션바가 겹치지 않도록 z-index/여백 재조정

## Coach / Parent / Admin 개선
- Coach: 오늘 헤드라인 + 타임라인 스트립으로 "다음 행동"이 즉시 보임. Evening Batch는 영상 중심 워크스페이스로 재편, 저장 상태 상시 노출
- Parent: 자녀 이름·최신 강습이 감성적 히어로로 승격, 대표 사진이 화면 중심, 리포트는 색상으로 잘한점/보완점/다음목표 구분
- Admin: "확인만 하는 대시보드"에서 "지금 처리할 업무" 큐가 최상단으로 승격, 통계는 보조 정보로 하단 배치

## 남은 기술적 한계
- localStorage + 메모리 기반 데모 상태 (다중 기기 동기화 불가)
- Google Fonts(Fraunces/Inter)는 CDN 의존 — 완전 오프라인 환경에서는 시스템 폰트로 폴백
- 실 브라우저 시각 QA(1440px/390px/360px, 가로 스크롤, 겹침)는 코드 레벨 점검까지만 완료 — 실기기 확인 필요
