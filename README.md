# YUSIMI Beta v2.2.0 — Product Design Refresh

v2.1.0의 기능(학생별 미디어 그룹, 주행영상 검토, Parent/Admin 즉시 반영)을 유지하면서
디자인 시스템과 모바일 사용성을 실사용 테스트 수준까지 재정비했습니다.

## v2.2.0 변경 요약
- 디자인 토큰(타이포/스페이싱/컬러) 재정의
- 모바일 하단 네비게이션 추가 (기존엔 모바일에서 화면 이동 자체가 불가능했던 결함 수정)
- Admin 테이블 → 모바일에서 리스트 뷰로 자동 전환
- Coach Evening Batch 저장 상태 표시(저장됨/저장 안 됨) + 모바일 고정 저장 액션바
- Parent 리포트를 "운영 도구"가 아닌 프리미엄 리포트 톤으로 재구성 (좋은점/보완점/다음목표 색상 구분)
- 이미지/영상 로드 실패 fallback 유지·강화
- 빈 상태(empty state) 문구 정리, 콘솔 오류 유발 요소 제거
